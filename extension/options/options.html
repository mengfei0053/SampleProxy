Global bypass

Applies to all custom proxy profiles and to Auto switch whenever a rule or the default selects a proxy. Effective bypass merges each profile's Bypass with this list (duplicates removed). Direct is already direct, and Chrome's System mode does not accept an extension bypass list, so Global bypass does not apply while System is active.

Auto switch

When Auto switch is on, Chrome uses a PAC script. The first matching rule wins. Both the chosen profile's Bypass list and Global bypass still connect directly. The System profile cannot be chosen per site, because a PAC script has no "use the operating system proxy" result.
